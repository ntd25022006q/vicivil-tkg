# v1.2.5 — Interactive graph tooling release

Visualization release, **zero content change** — no data/index/benchmark edits;
retrieval metrics remain the frozen v1.2 measurement.

## What changed
- The law-level temporal graph explorer (`docs/graph/explorer.html`) is rebuilt
  on **Cytoscape.js 3.30.2** (replacing the general-purpose chart library):
  lane-grouped layout (10 law families), collision-free pixel-packing of
  overlapping sub-lanes computed offline, time-travel slider 1996-2026
  (future hidden / replaced dimmed / live in-force count), short statutory
  labels on external amending laws, per-law provenance drawer, law search,
  lane chips, PNG export.
- The timeline tab is now an explicit **Vega-Lite 5.21.0 spec**
  (`docs/graph/law_timeline.vl.json`) — temporal Gantt with successor edges
  and an "today" marker, palette-matched to the network.
- Manifest grows from 41 to **42 entries** (adds `law_timeline.vl.json`).
- `CITATION.cff` bumped to 1.2.5 (2026-10-18); DATASHEET + READMEs updated.
- Full pre-release sweep green across both mirrors: no secrets / invisible /
  CJK glyphs, all JSON/JSONL/GEXF parse, manifests byte-equal.
